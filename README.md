## Overview

Virtual Machines runs KVM virtual machines on your Linux hosts from Termix. It talks to libvirt over SSH, so there is nothing else to install. Each host gets a tab for its VMs, storage and networks, and All VMs lists every VM you have.

Read the [docs](https://docs.termix.site/plugins/virtual-machines) to set it up and use it.

<br />

## Features

- Start, stop, pause, reboot and clone VMs
- New VMs from cloud images, ISOs or empty disks, with cloud-init
- Change CPUs, memory, disks, network cards and the raw XML
- Snapshots and autostart
- Storage pools, volumes, downloads and virtual networks
- Graphical and serial consoles
- Jobs that run on the host and survive a Termix restart
- Alerts when a VM crashes or a pool fills up
- A VM panel beside SSH terminals, a dashboard card and host page tiles
- Termix actions for Operations Center, Automations, Fleets, the CLI and the assistant
